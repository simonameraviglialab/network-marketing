# Una seconda te per il tuo network

Pagina di presentazione commerciale di meravigliä Lab per leader di network marketing: assistente digitale su Telegram che segue i venditori con la voce e lo stile della leader.

- `index.html`: pagina statica unica, senza dipendenze da installare (solo Google Fonts). Aprila nel browser.

Contenuti: animazione del network (oggi / tra 6 mesi), chat di esempio, calcolatore del ritorno, investimento (3.500 € una tantum + 50 €/mese) con offerta valida fino al 30 novembre 2026.
